## Desviaciones respecto a las versiones del plan

Las versiones directas de `package.json` son las de PLAN §3, sin `^` ni `~`. Si al instalar alguna
no casa con otra, se baja a la última compatible, se comprueba la licencia con `npm view` y se anota
aquí.

Ninguna. `npm install` resolvió sin conflictos de pares las 50 versiones de PLAN §3 (incluida
TypeScript 6.0.3, D-R3) y el lock las confirma una a una; la prueba `scripts/licencias.test.mjs`
vuelve a comprobarlo (sin `^` ni `~`, versión del lock igual a la declarada).

## Notas de la tarea 0

- **Versión de Node.** El paquete **no declara `engines`** (es de navegador; D-R25). El desarrollo
  declara `devEngines.runtime` `>=24.15` con `onFail: "warn"`: `jsdom` 31, `stylelint` 18,
  `stylelint-config-standard` 41 y tres paquetes más, todos de desarrollo, piden `^24.15.0`. Con
  Node 24.14.1 npm muestra avisos (`EBADENGINE` de esos paquetes y `EBADDEVENGINES` del propio
  `package.json`) y todo funciona (`npm ci`, pruebas y lint pasan); conviene usar Node 24.15 o
  posterior.
- **Instalación.** `.npmrc` lleva `ignore-scripts=true` y `save-exact=true`: no se ejecutan scripts
  de instalación (`playwright-core` no descarga navegadores; las e2e y las capturas usan el Edge o
  el Chrome instalados con `channel`). No existe ninguna carpeta `ms-playwright`.
- **MPL-2.0 (consulta Q-6).** `lightningcss` y sus binarios por plataforma son la única licencia con
  copyleft débil del árbol; llegan como transitiva de desarrollo de Vite. **Se usa por defecto
  mientras Javier no decida; no se distribuye** (`files` sólo incluye `dist/`). Alternativa:
  `build.cssMinify: 'esbuild'` y sin `lightningcss` en el flujo de compilación. Los `targets` de
  lightningcss cambian el CSS publicado (por ejemplo, convierten `:dir()` en `:lang()`, que no
  funciona con `?dir=rtl`; por eso D-R22 prohíbe `:dir()` en el CSS).
- **Phosphor es de desarrollo.** `@phosphor-icons/react` (MIT) pasa a `devDependencies` (D-R19): sólo
  lo usa `scripts/gen-icons.mjs` para generar `src/ui/icon-data.ts`; quien instala el paquete ya no
  lo trae.
- **Sin `axe-core` ni `eslint-plugin-jsx-a11y`** (MPL-2.0, D-R5): la accesibilidad se prueba por rol
  y nombre accesible con Testing Library.
- **Cómo regenerar.** `npm run licencias` reescribe sólo el bloque entre marcadores;
  `npm run licencias -- --check` falla ante una licencia no permitida o si el bloque está
  desactualizado (forma parte de `npm run check`).
