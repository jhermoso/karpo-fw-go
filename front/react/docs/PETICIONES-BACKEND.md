# Peticiones al backend de Karpo Go desde el front React

Lo que el front React (`front/react`) necesita del backend y no cambia por sí mismo (el carril
sólo toca `front/react`). Cada petición dice qué falta, cómo lo resuelve hoy el front y qué se
propone. Fuentes: `docs/analisis/02-api-karpo-go.md` (A2), `01-runtime-angular-y-configuracion.md`
(A1) y las notas de las tareas T1 a T7 (`docs/notas/`). Primera versión: 2026-11-27 (plan, ronda 1).
Ronda 2 (2026-11-27): R5 añade B-24 a B-26 desde las notas `docs/notas/R2-*.md` (catálogos traducibles, total sin filtrar y
servicio de teselas propio). Ronda 3 (2026-11-27): R3-6 añade B-27 (sello de auditoría) y B-28 (recuento de hijos, opcional)
desde `docs/notas/R3-R2.md`.
Consolidada el 2026-11-27 por la tarea 8: las peticiones repetidas por varias tareas se fundieron
en una (la columna «Origen» dice quién la pidió) y la numeración sigue sin huecos.
